# TaxPal — Personal Finance & Tax Estimator

TaxPal is a modern web application designed to help users track personal finances, manage budgets, categorize transactions, and generate real-time tax estimations.

## 🚀 Features

- **User Authentication:** Secure authentication powered by Firebase Auth.
- **Budget Management:** Set, track, and monitor budgets by category.
- **Transaction Tracking:** Record income and expenses with detailed categorization.
- **Tax Estimation:** Automated tax liability calculations and projections.
- **Financial Reports:** Visual breakdowns and summaries of income vs. expenses.

## 🛠️ Tech Stack

- **Frontend:** React, React Router, Recharts, Axios, Firebase
- **Backend:** Node.js, Express, MongoDB (Mongoose), JWT, Firebase Admin SDK
